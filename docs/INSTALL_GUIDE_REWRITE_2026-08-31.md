# インストール手順書の書き直し — 2026-08-31

新ファイル: `packaging/dmg/インストール手順.txt`
実測記録: `docs/evidence/install-guide-2026-08-31/`

既存の `packaging/dmg/はじめにお読みください.txt` は消さずに残した。
どちらを DMG に焼くかは `packaging/build_dmg.sh` の 1 行で決まる（現状は旧ファイルのまま）。

## なぜ書き直したか

オーナー評価は「俺でも難しい」。実機で手順どおり進めて permission denied で止まった。
止まった場所は「ターミナルで `xattr -dr com.apple.quarantine` の末尾スペースの後へ
DMG をドラッグ」の行で、コマンドを打つ前提が読み取れず、DMG のパスだけが実行された。

## 決めたこと: ターミナルを必須手順から外した

macOS 26.3.1 で実測した結果、署名も公証もない ad-hoc 署名アプリでも
**システム設定 → プライバシーとセキュリティ →［このまま開く］の経路が使える**。
これを既定の道にして、`xattr` は「困ったとき」へ落とした。

実測で確定した経路（詳細と画面写真は evidence/README.md）:

1. 起動 → 「"VIEWPORT BREAK.app" は開いていません」→［完了］
2. システム設定 → プライバシーとセキュリティ → 一番下「セキュリティ」
   → 「お使いの Mac を保護するために … がブロックされました。」→［このまま開く］
3. 確認ダイアログ「… を開きますか?」→［このまま開く］
4. 管理者のユーザ名とパスワード（Touch ID 機では指紋のはず）
5. 起動してセットアップ完了

**右クリック →「開く」は使えない。** macOS 26.3.1 で実際に試したところ、
ダブルクリックと同じブロックダイアログが出た。旧手順書の想定どおり、
この経路は既に無効になっている。

## 潰した問題

| 旧手順書の問題 | どうしたか |
|---|---|
| 冒頭が「まだ開かないでください」＋ SHA-256 照合 | 冒頭を「最初にこれだけ読んでください（3 行）」に変更。SHA-256 は末尾の任意手順へ |
| ターミナルで `xattr` を打たせる（実際の詰まり所） | 必須手順から削除。「困ったとき」に、コピペ 1 行・ドラッグ操作なしの形で残した |
| 拡張 ID の文字列一致を必須確認にしていた | 必須から外し、「幅を押しても何も起きない」の切り分け項目へ移動。一致しない時に何をするか（削除して読み込み直す）まで書いた |
| オートメーション許可が、なぜ要るかの前に手順として出る | 理由（Chrome 自身は 500px より狭くできない）を先に 3 行で置き、その後に手順 |
| 「左の VIEWPORT BREAK を右の Applications へ」 | DMG 内の並びは名前順の自動整列で、実際は Applications が左。位置ではなく名前で指す書き方に変更 |
| ブロックダイアログの文言が実物と違う（「開発元によって認証されていないため、開けません。」） | 実測した文言に差し替え |
| 「Return で確定させず」とだけ書いてあった | 青いデフォルトボタンが［ゴミ箱に入れる］であることを、手順に入る前に明示 |
| 拡張フォルダの選択で［開く］と書いていた | 実際のボタンは［選択］。パネルの見出しも実文言に差し替え |

## 書き方の方針

- 各手順の 1 行目は「何をするか」。理由と補足はその後ろ。
- 1 手順 = 1 操作。「〜してから〜」を 1 行に詰めない。
- 画面に出る文言はそのまま引用する。
- 警告が出るのは正常だと、手順に入る前に伝える。
- 番号は 1〜22 の通し。読み手が今どこにいるか見失わないようにする。

## 見つけたが直していないこと（follow-up）

- `build/VIEWPORT BREAK 1.0.1 - MacBook入れ直し手順.txt` の SHA-256 が実物と不一致。
  記載 `8ebb2689…` / 実物 `fc257912…`。この手順書どおりに照合すると、正しい DMG が
  改変されていると判定される。build/ は git 管理外のため、この dispatch では触っていない。
- `packaging/build_dmg.sh` は今も旧 `はじめにお読みください.txt` を焼く。
  新手順書へ差し替えるなら DMG の再ビルドと SHA-256 の再掲載が要る。
- DMG のアイコン配置を `.DS_Store` で固定していないため、並びが Mac 任せになる。
  「アプリを右の Applications へドラッグ」という一般的な図にできない。
